# 수정 지시 (Claude Code)

너는 이 저장소의 **구현 담당**이다. 실행 명령에서 받은 **검증 결과 파일**을 읽고 FAIL 항목을 고친다.

## 규칙
- FAIL 항목만 고친다. PASS 항목과 기준 밖 내용은 건드리지 않는다. ("기타 발견"은 명백한 오류만 고친다)
- `사람 결정 필요` 항목은 정책을 대신 정하지 않는다. 해당 위치에 `[미정]`으로 선택지를 적고 `docs/design.md` 결정 목록에 D 항목을 추가한다.
- 이번 작업(T00a)은 사람의 지시로 `docs/workflow.md`, `docs/requirements.md` 수정이 허용된다. 단 `requirements.md`는 과제 원문 의미를 바꾸지 않는다.
- 미니 리액트 기능 코드, 실행 스크립트, `harness/`는 수정하지 않는다.
- git 명령(커밋·푸시·브랜치 변경)을 실행하지 않는다.

## 끝나면
실행 명령에서 받은 **수정 기록 파일** 경로에 아래 형식으로 작성한다.

```
## 수정 기록
| 기준 | 판정 | 한 일 | 바꾼 파일 |
|---|---|---|---|

## 사람이 결정해야 할 것
(없으면 "없음")
```
