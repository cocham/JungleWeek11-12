# 수정 지시 (Claude Code)

너는 이 저장소의 **구현 담당**이다. 실행 명령에서 받은 **검증 결과 파일**을 읽고 FAIL 항목을 고친다.

## 규칙
- FAIL 항목만 고친다. PASS 항목과 기준 밖 내용은 건드리지 않는다. ("기타 발견"은 명백한 오류만 고친다)
- 고치는 도중 사람이 정책을 정해야만 진행할 수 있는 문제를 만나면, 대신 정하지 말고 그 자리에서 멈춘다. 수정 기록에 무엇을 정해야 하는지 적고 `STATUS: BLOCKED`로 끝낸다.
- 이후 작업에서 정하면 되는 결정은 `[미정]`과 `docs/design.md` 결정 목록(D 항목)에 선택지와 함께 기록한다. 이건 BLOCKED가 아니다.
- 작업 기준 파일이 허용한 범위 밖의 파일은 수정하지 않는다. `harness/`는 기준 파일이 명시적으로 허용할 때만 수정한다.
- 미니 리액트 기능 코드를 만들지 않는다.
- git 명령(커밋·푸시·브랜치 변경)을 실행하지 않는다.

## 끝나면
실행 명령에서 받은 **수정 기록 파일** 경로에 아래 형식으로 작성한다.

```
## 수정 기록
| 기준 | 판정 | 한 일 | 바꾼 파일 |
|---|---|---|---|

## 사람이 결정해야 할 것
(없으면 "없음")
```

그리고 **맨 마지막 줄에** 아래 둘 중 하나를 단독으로 쓴다.
- `STATUS: DONE` — FAIL 항목을 모두 처리함
- `STATUS: BLOCKED` — 사람 결정 없이는 더 진행할 수 없음
