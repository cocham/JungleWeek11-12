# 설계

> 표기 규칙
> - `[확정]` 요구사항에서 나오거나 팀이 결정한 것. 결정한 날짜/사람을 함께 적는다.
> - `[미정]` 아직 정하지 않은 것. 코드로 먼저 정해버리지 않는다.
> - `제안:` AI나 팀원의 의견. 확정이 아니다.
>
> 미정 항목을 확정하면 아래 결정 목록의 상태를 바꾸고, 본문에 `[확정]`으로 옮겨 적는다.

## 1. 전체 흐름

`[확정]` (요구사항 R-P1-07, R-P2-07에서 나옴)

```
Phase 1:  실제 DOM ──domToVNode──▶ VNode ──diff(old, new)──▶ 변경 내역 ──patch──▶ 실제 DOM

Phase 2:  setState ──▶ FunctionComponent.update()
                         └─ 컴포넌트 함수 재실행 → 새 VNode
                         └─ diff(이전 VNode, 새 VNode) → patch
```

## 2. 모듈 구성

`[확정]` 들어가야 하는 모듈 (요구사항 기준)

| 모듈 | 역할 | 요구사항 |
|---|---|---|
| VDOM 변환 | 실제 DOM → VNode | R-P1-01 |
| 렌더 | VNode → 실제 DOM 생성 (테스트 영역 렌더, 노드 추가 시 필요) | R-P1-05 |
| Diff | 두 VNode 비교 → 변경 내역 | R-P1-02 |
| Patch | 변경 내역을 실제 DOM에 반영 | R-P1-03 |
| History | VNode 스냅샷 저장 / 뒤로 / 앞으로 | R-P1-07, 08 |
| FunctionComponent | hooks 배열, mount(), update() | R-P2-02 |
| Hooks | useState, useEffect, useMemo | R-P2-06 |
| Phase 1 검증 페이지 | 실제 영역 / 테스트 영역 / 버튼 3개 | R-P1-04 |
| 테스트 페이지 앱 | 주제 자유 | R-APP-01 |

`[미정]` 폴더/파일 구조 → D15

## 3. VNode 구조

`[미정]` → D04

제안: 아래처럼 시작하고 D04에서 확정
```
{ type: 'div', props: { id: 'a', class: 'b' }, children: [VNode, ...] }
텍스트 노드: { type: '#text', text: 'hello' }   // 또는 문자열 그대로
```

## 4. Diff

`[확정]` 과제가 "최소 변경을 찾는 5가지 핵심 케이스"를 요구함

`[미정]` 5가지를 무엇으로 볼지 → D05
제안: 흔히 쓰는 분류는 ① 노드 추가 ② 노드 삭제 ③ 타입(태그) 변경 시 교체 ④ 속성 변경 ⑤ 텍스트 변경. 자식 순서 변경(key)을 여기에 넣을지는 D07과 같이 결정.

`[미정]` diff가 변경 목록을 반환하고 patch가 적용할지, diff 중에 바로 DOM을 바꿀지 → D06

## 5. History

`[확정]` Patch할 때마다 새 VNode 저장, 뒤로/앞으로 이동 시 두 영역 모두 갱신 (R-P1-07, 08)

`[미정]` 저장 구조와, 뒤로 간 상태에서 새로 Patch하면 앞쪽 기록을 버릴지 → D09

## 6. FunctionComponent / Hooks

`[확정]`
- 함수형 컴포넌트만 사용 (R-P2-01)
- `FunctionComponent` 클래스가 hooks 배열을 들고, `mount()` / `update()` 제공 (R-P2-02)
- State와 Hook은 루트 컴포넌트에만, 자식은 props만 받는 순수 함수 (R-P2-03, 04)
- 상태 변경 시 자동 재렌더 + Diff/Patch 사용 (R-P2-05, 07)

`[미정]`
- 컴포넌트가 VNode를 만드는 방식 (h 함수 / 객체 리터럴 / 템플릿 문자열 파싱) → D13
- setState 직후 바로 재렌더할지, 모아서 할지 (Batching) → D10
- useEffect 실행 시점과 cleanup → D11
- 자식 컴포넌트에서 Hook을 호출했을 때 처리 (에러 throw / 무시 / 문서로만 금지) → D17
- 이벤트 핸들러(onClick 등)를 props로 어떻게 붙이고 교체할지 → D12

## 7. 테스트

`[확정]` 모듈별 단위 테스트 + 화면 기능 테스트 (R-Q-01, 02)
`[미정]` 테스트 도구와 실행 방법 → D02
