# 작업 목록

> 칸 설명
> - **유형**: `결정`(결정 자체가 산출물) / `문서` / `설정` / `구현`
> - **선행 작업**: `완료` 상태여야 하는 작업 ID
> - **필요 결정**: 시작 전에 `design.md`에서 확정돼 있어야 하는 결정 ID
> - **산출 결정**: 이 작업이 확정하는 결정 ID. 결정 작업은 산출 결정을 필요 결정에 넣지 않는다
> - **학습**: `docs/learning.md`의 해당 절, 또는 `해당 없음`
>
> 시작 조건: 상태 `대기` + 선행 작업 모두 `완료` + 필요 결정 모두 `확정`.
> 필요 결정이 미정이면 작업을 시작하지 말고 `workflow.md` ② 결정 절차부터 진행한다.
>
> 상태: `대기` / `진행 중` / `검증 중` / `학습 확인 대기` / `완료` / `보류` — 전환 규칙은 `workflow.md` 4절
>
> 작업을 더 쪼개야 하면 `T05a`, `T05b`처럼 추가한다. 순서를 바꿀 땐 이유를 `status.md` 인계 기록에 남긴다.
