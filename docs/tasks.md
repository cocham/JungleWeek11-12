# 작업 목록

> 규칙
> - 한 번에 한 작업만 `진행 중`으로 둔다.
> - 완료 기준을 모두 만족해야 `완료`. 학습 확인까지 끝나야 다음 작업으로 넘어간다.
> - `선행 결정`에 적힌 D 항목이 `미정`이면 그 작업은 시작하지 않는다.
> - 작업을 더 쪼개야 하면 `T05a`, `T05b`처럼 추가한다. 순서를 바꿀 땐 이유를 `status.md` 인계 기록에 남긴다.
>
> 상태: `대기` / `진행 중` / `검증 중` / `완료` / `보류`
